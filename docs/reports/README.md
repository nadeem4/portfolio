# Implementation reports

Working notes written while building the features behind PRs #3–#9. They lived as untracked files inside per-feature git worktrees under `.claude/worktrees/`, and were archived here when those worktrees were removed on 2026-08-13.

They are a historical record, not live documentation — each describes the state of the code at the time it was written, so treat anything here as potentially stale. `README.md` and the design specs in `docs/superpowers/specs/` are the current sources of truth.

One file is not a report: `repo-descriptions-draft.md` holds drafted GitHub descriptions for repos that had none. Eight of the nine drafts were applied to GitHub; only `nutrient_detector` was left blank, deliberately — it contains reference PDFs rather than source code.
